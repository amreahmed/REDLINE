Objects in the Ephemeris
--------------------------------------------------------

     This file contains the location of the M2020 landing site
     JEZ (actual, 2021-03-03 solution) on the surface of Mars. The landing
     site NAIF ID and name are -168900 and 'M2020_LANDING_SITE'.


Approximate Time Coverage
--------------------------------------------------------

     The coverage of this file is:

        COVERAGE BEGIN TIME (TDB)     COVERAGE END TIME (TDB)
        -------------------------     ------------------------
        2000 JAN 01 00:00:00.000      2100 JAN 01 00:00:00.000


Site Coordinates
--------------------------------------------------------

     This file contains the landing site location defined by with the
     following Gaussian coordinates:

        Lon =  77.45088572 degrees East
        Lat =  18.64875816 degrees North
        Alt =  -2.236421 km

     The corresponding XYZ coordinates were computed by PINPOINT for
     the triaxial ellipsoid surface defined by the body 499 radii
     from PcK file 'pck00010.tpc'.
