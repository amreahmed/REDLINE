Objects in the Ephemeris
--------------------------------------------------------

     This file contains the location of the INSIGHT target landing site
     ops181206 (actual site based on the MRO HIRISE image taken on Dec 6, 2018) on the surface of Mars. The landing
     site NAIF ID and name are -189900 and 'INSIGHT_LANDING_SITE'.

Site Coordinates
--------------------------------------------------------

     This file contains the landing site location defined by with the
     following Gaussian coordinates:

        Lon =  135.623447 degrees East
        Lat =  4.555681 degrees North
        Alt =  -2.986224 km

     The corresponding XYZ coordinates were computed by PINPOINT for
     the triaxial ellipsoid surface defined by the body 499 radii
     from PcK file 'pck00010.tpc'.
