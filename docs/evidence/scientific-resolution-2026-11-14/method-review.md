# Terrain-method review — 14 November 2026

Read-only scientific assessment of REDLINE checkpoint `9d70fac`. No production terrain, application calculation, map transform or route gate was changed. The preserved 65,536-cell CTX crop remains the current numerical source.

## Decision for the current source

Keep physical CTX slope and terrain-cost output unavailable. The exact numerical samples and metre encoding are verified, but their final vertical interpretation is not. Comparing unaltered source values to explicitly defined separate reference products is useful evidence; numerical similarity does not authorize relabelling the CTX band or applying a guessed datum correction. Shared control lineage limits the independence of a reference, as described below.

A difference between two native provider values can honestly be reported as a **provider-value difference in metres**. Dividing it by a supported horizontal baseline yields a **provider-height gradient index**. These are operations on the archived scalar field, not independently validated physical slopes. If exposed later, they need a distinct model-only status and persistent datum qualification, must remain separate from the existing physical-slope gate, and must not feed route costs or human-traverse recommendations. This review does not recommend adding that potentially confusing index during the present resolution milestone.

The datum distinction is scientifically consequential. For a known areoid model `N` and radius field `r`, areoid height is `H = r - N`; height above a fixed sphere is `h = r - R`. Thus `h = H + N - R`, and a spatial derivative of `N` changes radial-reference gradients. A constant offset cancels, but a spatially varying correction does not. [Gwinner et al. (2009), DOI 10.1016/j.epsl.2009.11.007](https://doi.org/10.1016/j.epsl.2009.11.007), section 3, distinguishes HRSC spheroid and areoid DTMs and identifies areoid heights as useful for gravity-driven processes and regional slope angles. That is background methodology, not the vertical contract for this CTX TIFF. Neither a radial-reference gradient nor an areoid-reference gradient should be called an astronaut-safety measurement.

## Reference comparisons that are supported

The MOLA fields also have different statistics: the radius raster contains bin means, while topography contains bin medians. Subtracting the areoid raster from a mean-radius raster is therefore not an exact consistency equation for separately binned median topography. Missing observation bins may contain interpolated values. A native 20 m CTX cell is not a kilometre-scale MOLA bin statistic. ## Scale and uncertainty limitations

[Kirk et al. (2020), DOI 10.5194/isprs-archives-XLIII-B3-2020-1129-2020](https://doi.org/10.5194/isprs-archives-XLIII-B3-2020-1129-2020), evaluates Jezero stereo DTMs and distinguishes post spacing from measured spatial resolution. Its abstract reports horizontal resolution of 10–20 image pixels, versus commonly used 3–5-pixel DTM sampling. Those study results are not exact error bars for every preserved cell. They do establish why 20 m posts must not be described as resolving every 20 m terrain feature. Derivatives can amplify local noise; smoothing changes the modeled terrain and would require a separately documented derivative pipeline. This assessment does not smooth or resample the existing crop.

Current source editing, blending and missing per-cell stereo/fill provenance remain limitations even if the vertical datum is later resolved. Do not reinterpret all finite cells as independent stereo measurements or sufficient support for hazards, rock-scale roughness or human walking.

## Coarse MOLA alternative

A separately labelled numerical MOLA context mode could use documented areoid heights and supported kilometre/hectometre baselines. Prefer a bounded native 128-pixel/degree extraction with observation counts, rather than upsampling the existing 16-pixel/degree probes into a supposed fine route grid. Missing observed support should block derivatives by default; retain an explicit interpolation distinction. The current crop would contain only a small number of native MOLA bins. This is suitable for regional topographic context, not replacing 65,536 CTX cells or assessing fine astronaut traverses. A MOLA mode would require its own CRS, height, encoding, coverage, attribution and browser-access audit before implementation.
