Abstract
This product represents adirectional topographic slopes over 20 meter horizontal baselines within part of a candidate landing site for the Mars2020 mission. The slope map was derived from a CTX-based digital terrain model. This slope map was produced as part of an effort to characterize terrain within candidate landing ellipses for the Mars2020 mission and to aid entry, descent, and landing simulations for the mission. The parent DTM was constructed from a pair of CTX images using the stereo photogrammetry software SOCET SETÂ® (BAE Systems).
